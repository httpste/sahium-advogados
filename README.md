# Sahium Advogados

Desenvolvi este site para apresentar o escritório, as áreas de atuação e a trajetória dos sócios. Também reuni as perguntas mais frequentes e os canais de atendimento para facilitar o primeiro contato pelo WhatsApp.

O site foi feito com HTML, CSS e JavaScript. Para visualizar, basta abrir o `index.html` no navegador.

## Onde atualizar

- `index.html` — página inicial, perguntas frequentes e contatos.
- `quem-somos/` — história do escritório e filiações.
- `carla-sahium/` e `jefferson-lopes/` — perfis dos sócios.
- `assets/` — fotos e logotipos.
